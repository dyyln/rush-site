# Rush room images

Top-down layout tiles for the Rush rooms, 320x200 webp on the site surface colour.

## Source

Cropped from the arena overview image in Valve's Rush release post of 22 September 2026:

- Image: https://clan.fastly.steamstatic.com/images/3381077/4ccfe4f44119ac6ddd5cd39d24c907dd11f4c70a.png
- Post: https://store.steampowered.com/news/app/730/view/711161056325533826

Each tile was cut out of the image, the blurred backdrop was replaced with the surface colour, and the tile was scaled down.

Missing, shown as a placeholder card with the room name: 203 Trainyard, 205 Bloc, 206 Hydro, 207 Atomic, 208 Medusa, 209 Bear, 210 Steel, 211 Container and the Convoy decider. Valve's image also shows Playhouse, Tunnel, King of the Hill, Marksman and Horseshoe. Those names are not in the shipped rush_001 script, and nothing ties them to a script id, so they are left out.
